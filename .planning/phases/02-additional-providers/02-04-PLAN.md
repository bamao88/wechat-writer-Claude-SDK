# Plan 04: Real API Testing for All Providers

## Objective

Create comprehensive real API integration tests that verify all three providers (MiniMax, OpenAI, Claude) work correctly with actual API calls using credentials from the `.env` file.

Purpose: Ensure providers work with real APIs, not just mocked tests. Validate the complete integration chain from environment configuration to API response.

Output: `tests/test_real_api_providers.py` with integration tests for all providers.

## Context

@llm/providers.py
@llm/registry.py
@llm/config.py
@llm/base.py
@tests/conftest.py
@tests/test_minimax_connection.py

The existing `test_minimax_connection.py` demonstrates the pattern for real API testing using `@pytest.mark.skipif` to skip when credentials are missing. This plan extends that pattern to all three providers with a unified test structure.

  <name>Task 1: Create Real API Test Suite</name>
  <files>tests/test_real_api_providers.py</files>
  <action>
Create `tests/test_real_api_providers.py` with comprehensive real API tests for all three providers.

Structure:
1. Imports: pytest, os, asyncio, and required LLM modules
2. Helper function `check_provider_configured(provider_id: str) -> bool` to check if a provider has credentials
3. Test class `TestProviderFromEnv` with tests for each provider:
   - `test_minimax_from_env()` - Verify MiniMax provider loads from environment
   - `test_openai_from_env()` - Verify OpenAI provider loads from environment
   - `test_claude_from_env()` - Verify Claude provider loads from environment
4. Test class `TestProviderModelCreation` with tests:
   - `test_minimax_create_model()` - Verify MiniMax creates model instance
   - `test_openai_create_model()` - Verify OpenAI creates model instance
   - `test_claude_create_model()` - Verify Claude creates model instance
5. Test class `TestRealAPI` with async integration tests:
   - `test_minimax_real_api_call()` - Real API call to MiniMax
   - `test_openai_real_api_call()` - Real API call to OpenAI
   - `test_claude_real_api_call()` - Real API call to Claude

Each real API test should:
- Use `@pytest.mark.integration` marker
- Use `@pytest.mark.skipif(check_provider_configured('xxx'), reason='...')` to skip if not configured
- Use `@pytest.mark.asyncio` for async tests
- Create provider via `ProviderRegistry.from_env()`
- Create model via `provider.create_model()`
- Make a simple API call with a prompt like "Say 'Hello' and nothing else"
- Verify response is non-empty string

Use the pattern from `test_minimax_connection.py` for the real API test structure.
